## 📊 Projects

### 1. Movie Review Sentiment Analysis
**Tech Stack**: Flask, TensorFlow, Keras, HTML/CSS
**Description**: Real-time sentiment analysis of movie reviews using deep learning

**Key Features**:
- Pre-trained LSTM model for sentiment classification
- Word tokenization and sequence padding
- Interactive web interface with confidence scores
- Handles out-of-vocabulary words gracefully

**Demo**: Upload movie reviews and get instant sentiment predictions with confidence levels

### 2. Next Word Prediction with LSTM
**Tech Stack**: Streamlit, TensorFlow, Keras, Pickle
**Description**: Intelligent text completion system using LSTM neural networks

**Key Features**:
- LSTM model with early stopping for optimal performance
- Dynamic sequence length handling
- Real-time word prediction
- Comprehensive error handling

**Demo**: Type a phrase and watch the AI predict the next word in real-time
