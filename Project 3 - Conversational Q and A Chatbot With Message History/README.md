# Document Q&A Assistant
A powerful document question-answering application built with Streamlit, LangChain, and OpenAI. Upload documents or provide URLs to ask questions and get AI-powered answers.
Features

📄 Multiple Document Support: Upload PDF and text files
🌐 Web URL Processing: Process web pages directly
💬 Interactive Chat: Chat interface for natural conversations
⚙️ Configurable Settings: Adjust model, temperature, and processing parameters
🔒 Secure: API keys handled securely

# Quick Start

## Deploy on Render:

Fork this repository
Connect to Render
Deploy automatically


## Local Development:
bashpip install -r requirements.txt
streamlit run app.py

## Usage:

Enter your OpenAI API key
Upload documents or enter URL
Ask questions about your content



## Technologies Used

Streamlit: Web interface
LangChain: Document processing and chains
OpenAI: Language model
FAISS: Vector store for similarity search
PyPDF: PDF processing
